        還沒有收藏的站牌。
        在路線頁點右邊的 ☆ 就會加進來。

        對方點開連結會直接看到同一組站牌的即時到站時間（對方也需要自備 TDX 金鑰）。

        為什麼要自己申請金鑰？
        這是一頁放在 GitHub Pages 的靜態網頁，沒有後端可以替你保管密鑰。 金鑰只存在這支瀏覽器的 localStorage，不會送到 GitHub 或任何第三方， 每次查詢都是你的瀏覽器直接打 TDX。 去 TDX 會員註冊 申請一組免費金鑰（Client Id 與 Client Secret）， 免費額度是每天 5 萬次、每秒 50 次，個人用綽綽有餘。

        沒有金鑰也可以先看看。 打開會用一組固定的假資料 把畫面跑一遍，分享功能照常可用，但時間是假的。
        到站時間是 TDX 依據 GPS 回報推估的結果，塞車與號誌都會讓它跳動；
        路線與站序資料同樣來自 TDX，站牌實際位置以現場牌面為準。
